# Licenciamento

O licenciamento do código e dos dados deve ser definido antes de tornar o repositório público.

Sugestão de decisão institucional:

- **Código:** considerar uma licença permissiva (por exemplo, MIT ou BSD-3-Clause), após aprovação dos responsáveis.
- **Dados:** definir separadamente, considerando autoria, financiamento, acordos institucionais, localização de campo e política do patrocinador.

Até essa definição, recomenda-se manter o repositório **privado**.
