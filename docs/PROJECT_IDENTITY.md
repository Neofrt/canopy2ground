# Canopy2Ground

*Integrated monitoring of microclimate, soil water and precipitation*

**Canopy2Ground** is the public-facing name of the reproducible data-processing framework developed for the Capitão Poço ecohydrological monitoring project.

The name is used for the GitHub repository, technical documentation, releases and future data-access interface. Python is the current implementation language, but it is not part of the project name.

## Recommended references

- Repository: `canopy2ground`
- Display name: **Canopy2Ground**
- Subtitle: *Integrated monitoring of microclimate, soil water and precipitation*
