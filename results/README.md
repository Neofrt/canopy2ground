# Resultados e auditorias

Esta pasta é criada/atualizada pelo pipeline para armazenar diagnósticos, QA e resultados auxiliares.

Os arquivos gerados em `results/` não são versionados por padrão, pois mudam a cada nova atualização dos sensores. Resultados estáveis destinados a relatório ou publicação podem ser exportados para `docs/` ou publicados em uma release específica.
